```

conducting body itself. Do not use coaching sites, job-alert sites or news aggregators
as a source - use them only to locate the official document.

  - exam_id      : the id given in brackets below, unchanged
  - vacancies    : the total figure exactly as printed in the notification
  - source_url   : direct link to that notification or PDF
  - doc_date     : the date printed on the document (YYYY-MM-DD)
  - advert_no    : the advertisement / notification number, if it has one
  - applicants   : ONLY if the document or the conducting body states it. If it does
                   not, write null. Do NOT derive it, estimate it, or infer it from a
                   ratio. A null here is correct and useful; a guess is not.
  - year         : the recruitment cycle the figure belongs to

Check whether more than one notification is currently active (for example a general
cycle plus a separate backlog or special recruitment drive). Report each separately;
do not merge them into a single number.

Capture a screenshot of the exact table or line that states the vacancy figure.

If you cannot find a document from the conducting body itself, say so plainly and
report nothing for that exam rather than falling back to a secondary figure.
```
